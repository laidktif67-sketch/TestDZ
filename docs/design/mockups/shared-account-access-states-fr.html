États du compte et accès

États clairs pour la connexion, la session et les autorisations.

Hors ligne

Vous êtes hors ligne

La page ne peut pas être actualisée. Vérifiez votre connexion, puis réessayez.

Session expirée

Veuillez vous reconnecter

Votre session a expiré pour des raisons de sécurité. Reconnectez-vous pour continuer.

Compte restreint

Votre compte est suspendu

Votre session peut être encore active, mais l’accès à TestDZ est restreint. Consultez l’avis ou contactez l’assistance.

Accès bloqué

Ce statut concerne le compte, pas le réseau. Une nouvelle connexion ne supprime pas la restriction.

Le recours apparaît uniquement si le serveur confirme une suspension active et un délai ouvert.

Accès refusé

Vous n’avez pas accès à cette page

Votre compte est actif, mais votre rôle ne permet pas cet accès. Retournez à votre espace.

Introuvable

Cette page est indisponible

L’élément a peut-être été supprimé ou le lien est incorrect. Retournez à votre espace.
