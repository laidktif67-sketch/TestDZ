# Slides Delegation

Presentation creation is owned by the dedicated `slides` skill.

When a request involves a pitch deck, presentation, slide narrative, slide layout, slide copy, or HTML slide output:

1. Activate the `slides` skill when it is available.
2. Do not run a second slide workflow from `design`.
3. Keep this file as a routing note only; slide creation guidance and references live under `.skill-lab/project/slides/`.

The `design` skill remains responsible for logo design, corporate identity, icons, and social-photo creative work.
